# PlexLyricSync

Plex Base Url should be in this format: http://X.X.X.X:XXXXX
To find the port your Plex instance uses check: Settings > Remote Access in Plex

The translation feature in this app is powered by LibreTranslate you will need to maintain your own instance of LibreTranslate and provide an endpoint url in the config file.
The endpoint should be in this format: http://X.X.X.X:XXXXX
